# US States Game 🇺🇸

An interactive Python game where players guess the names of all 50 U.S. states.

## About the Project

This project uses Python Turtle graphics and Pandas to create an educational guessing game.
Correctly guessed states appear on the U.S. map.

If the player exits the game, a CSV file containing missed states is automatically generated for learning purposes.

## Features

* Interactive U.S. map
* State name guessing game
* Score tracking
* CSV data handling with Pandas
* Automatic "states to learn" file generation

## Technologies Used

* Python
* Turtle Graphics
* Pandas

1. Install Python

```bash

```

3. Run the project:

```bash
python main.py
```
