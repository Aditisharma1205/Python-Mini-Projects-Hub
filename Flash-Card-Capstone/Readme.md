# 🧠 Flash Card App

A Flash Card application built using Python and Tkinter to help users learn French vocabulary through interactive flashcards.

---

## ✨ Features

- Randomly displays French words
- Automatically flips cards after a few seconds
- Reveals English translations
- Tracks learned words
- Saves progress using CSV files
- Interactive graphical interface

---

## 🛠 Technologies Used

- Python
- Tkinter
- Pandas
- CSV Files

## 🚀 How to Run

1. Install Python
2. Install required package:

```bash
pip install pandas
```

3. Run:

```bash
python main.py
```
