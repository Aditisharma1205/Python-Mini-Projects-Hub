# Snake Game in Python 🐍

A classic Snake Game built using Python and the Turtle graphics module.

## Features

* Snake movement controls
* Food collision detection
* Score tracking system
* Game over detection
* Smooth gameplay using Turtle graphics

## Technologies Used

* Python
* Turtle Module

## Project Structure

```bash
Snake-Game/
│
├── main.py
├── snake.py
├── food.py
├── scoreboard.py
└── README.md
```

## How to Run

1. Install Python on your system
2. Download the project files
3. Open the project folder
4. Run:

```bash
python main.py
```

## Controls

* ↑ : Move Up
* ↓ : Move Down
* ← : Move Left
* → : Move Right
