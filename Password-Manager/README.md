# 🔐 Password Manager

A desktop Password Manager application built using **Python** and **Tkinter**. This application helps users generate strong passwords, save credentials, and search for stored login information.

---

## ✨ Features

- Generate secure random passwords
- Automatically copy generated passwords to clipboard
- Save website credentials in a JSON file
- Search saved credentials by website name
- User-friendly graphical interface
- Error handling for missing data files
- Persistent data storage using JSON

---

## 🚀 Getting Started

### Prerequisites

Make sure Python is installed on your system.

Install the required dependency:

```bash
pip install pyperclip
```

### Run the Application

```bash
python main.py
```

## 📸 Application Features

### Generate Password
- Creates strong random passwords using:
  - Letters
  - Numbers
  - Special Characters

### Save Credentials
- Stores website, email, and password data in a JSON file.

### Search Credentials
- Retrieves saved login information for a website.
