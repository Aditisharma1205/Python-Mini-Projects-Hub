# Turtle Race Game 🐢

A simple Turtle Race Game built using Python Turtle graphics.

## About the Project

In this game, the user places a bet on which colored turtle will win the race.
The turtles then move forward randomly until one reaches the finish line.

## Features

* Multiple racing turtles
* Random turtle movement
* User betting system
* Winner detection
* Beginner-friendly Python project

## Technologies Used

* Python
* Turtle Module
* Random Module

## How to Run

1. Install Python
2. Save the code in a file named `main.py`
3. Run the program:

```bash id="n2j4cx"
python main.py
```

## Game Controls

* Enter a turtle color when prompted
* Watch the turtles race
* See if your bet wins 🎉
