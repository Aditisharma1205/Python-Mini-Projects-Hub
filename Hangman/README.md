# Hangman Game 🎯

A classic Hangman word guessing game built using Python.

## About the Project

This project is a text-based Hangman game where the player tries to guess a hidden word one letter at a time before running out of lives.

The game includes random word selection, user input handling, and visual progress tracking.

## Features

* Random word selection
* Letter-by-letter guessing
* Lives/attempt tracking
* Win and lose conditions
* Beginner-friendly Python project

## Technologies Used

* Python
* Random Module
