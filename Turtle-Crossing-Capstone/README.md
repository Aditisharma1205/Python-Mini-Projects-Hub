# Turtle Crossing Capstone Project 🐢🚗

A fun arcade-style Turtle Crossing game built using Python Turtle graphics.

## About the Project

In this game, the player controls a turtle and tries to cross the road while avoiding moving cars.
Each successful crossing increases the game level and the car speed, making the game more challenging.

## Features

* Player-controlled turtle movement
* Moving cars with random positions
* Collision detection
* Level progression system
* Increasing game difficulty
* Game over screen

## Technologies Used

* Python
* Turtle Module
* Random Module

## How to Run

1. Install Python on your system
2. Download the project files
3. Open the project folder
4. Run:

```bash
python main.py
```
